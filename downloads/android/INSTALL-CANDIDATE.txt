EchoScript 0.6.0 Android development candidate
===============================================
This package is for synthetic evaluation. It is not an accepted release candidate
and has not passed all release gates. Android 10 or later is required.

Install only the APK from this same package after checking SHA256SUMS.txt. The
BUILD.txt file identifies its source commit and GitHub Actions run. It is a
debuggable preview build, not an owner-signed production release.

This 0.6 test build uses the separate application ID
org.echoscript.app.preview06 and appears as "EchoScript 0.6 Test". It can be
installed alongside the 0.5.1 preview and has its own separate, initially empty
vault; cases do not move between apps automatically. Use synthetic test files.

Separate 0.6 CI builds can still use different signing keys, so Android may
refuse to update an earlier 0.6 test build. Do not remove or reset either app
until you have exported, independently verified and safely stored any cases you
need: uninstalling can erase that app's vault. Owner signing and vault-preserving
upgrade testing are still outstanding.

In Cases, tap Choose audio file. After choosing one file, confirm that the
Selected recording panel shows its name, then tap Import selected audio. The
panel shows progress and lets you retry an unsuccessful import. The exact
source bytes are preserved before decoding. If an app interruption is reported,
check Cases for a preserved copy before selecting the recording again. Actual
physical-device testing, including the Galaxy S22+, remains outstanding.

In Analyze, tap the timeline to seek or drag to select a range. Playback and
clipping controls are below it. The quick spectrum samples brief windows; the
optional full-recording scan covers the recording with overlapping windows and
shows a coarse overview. It can take a long time for large files. Keep the app
open, and use Cancel if needed. For finer detail, inspect a selected time range.

Quick presets, effect groups and effect choices scroll horizontally. Swipe to
reach more controls. Each effect has an enable switch, a signed strength slider
and a numerical field. Changes remain drafts until rendered. Saved renders and
their recipes remain in revision history when an earlier state is restored.

Settings includes Explore possible plans: All tools, Free preview, Subscription
preview and One-time preview. All tools is the evaluation default. The other
choices only simulate proposed access; they do not create or record a purchase.
No prices, payments, subscription or production license service are active.
Existing cases, playback, history, verification and exports remain accessible
in every preview. The choice resets when the app process restarts.

Transcript segments accept a separate Examiner note (not spoken words). Notes
are searchable and save as new transcript revisions; adding a note alone does
not verify speech. Native documents label notes separately. SRT, VTT and CTM
contain speech/timing only. Review the saved revision before exporting.

The app is local-first and runs its bundled English speech model on the device.
The optional experimental Whisper service in the source tree is not connected
to this Android build. Individual WAV and document exports are plaintext;
protected case packages require a separately retained passphrase. Device
checkpoint signatures do not identify the examiner.

For current published downloads and release status, see:
