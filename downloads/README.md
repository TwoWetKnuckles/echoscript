Android 10 or later. Extract the `EchoScript-Android` folder, open `EchoScript-offline-preview.apk`, then choose **Load synthetic speech sample** in **Cases**. The APK includes its speech models. The ZIP includes `INSTALL.txt`, `SHA256SUMS.txt`, build provenance and license notices.

**Development preview for synthetic evaluation. BETA GATE: NOT PASSED.** The APK is debuggable and development-signed. Verify the checksum before installing. Preserve test case exports before removing an older preview if Android rejects the update. Use protected storage for plaintext exports.
