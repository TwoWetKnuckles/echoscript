EchoScript is an Android 10+ local audio workbench with a separate browser companion, local provider service, independent case tools and standalone documentation app. Public source development was authorized on November 1, 2026. No case data, provider credentials or signing keys are authorized for publication.

## Application workflow

Import preserves and hashes original bytes before decode. Keystore-protected Tink Streaming AEAD encrypts the persistent vault. Analysis, audio renders, recognition inputs, raw provider responses, normalized transcripts, examiner edits and export records retain immutable revision, hash, provenance and audit linkage. Undo or recipe replay selects/branches from saved artifacts; it does not replace earlier evidence.

The Android workbench uses graphite/cyan Material surfaces, shared cards, timeline/playback controls, compact presets and effect panels, time/frequency inspection, region ordering, A/B comparison, searchable notes and explicit examiner review. ClearVoice runs locally with before/after/off recipe placement. Vosk is the local default. Optional Whisper uses the configured companion, server-side API key and approval of each exact prepared payload. All implemented tools are available.

Local render and Vosk jobs now use encrypted persistent requests and WorkManager foreground execution. Only an opaque job UUID enters the scheduler. Completed stages are authenticated and hash-checked before reuse; failure/cancellation retains settings for explicit retry. A combined render/transcribe request persists the local continuation. Whisper approval and session credentials are never queued. See [background processing](/docs/android/background-processing) for restart, cancellation and scope limits.

## Source responsibilities

| Component                                                             | Responsibility                                                                                                        |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Android `EvidenceVault`, `OfflineWorkflow`                            | Encrypted originals/artifacts, canonical snapshots, audit, analysis, render, local recognition and revisioned review  |
| Android `ProcessingPlan`, `ProcessingJobs`                            | Validated encrypted local requests, serialized worker execution, persistent cancellation and completed-stage recovery |
| Android `MainActivity`, `AudioWorkbench`, `WorkspaceCard`, `AppTheme` | Consistent navigation, accessible controls, shared card rhythm and appearance                                         |
| `packages/evidence`, `packages/audio`, `packages/exports`             | Browser/domain contracts, DSP, provenance and exports                                                                 |
| `packages/case-security`, `tools/case-protect`, `tools/case-verify`   | Protected transfers, historical checkpoints and independent verification                                              |
| `services/api`                                                        | Optional local provider mediation; no evidence persistence or secret logging                                          |
| `apps/docs`                                                           | Separate Fumadocs app mirroring canonical Markdown; design/deployment work remains paused                             |

## Release and validation

[Downloads](/docs/downloads) is the authoritative published APK/ZIP entry and lists exact source and hashes. Source changes after that checkpoint require their own checks. Candidate 2 uses an isolated development package, `org.echoscript.app.candidate06r2`, version `0.6.0-candidate.2` / 10, to preserve already-installed candidate vaults when CI signing identities differ. Owner production signing remains separate.

[QA status](/docs/qa/status) records executed results and limits; [request reconciliation](/docs/qa/request-reconciliation) tracks the confirmed scope. Physical-device acceptance, advanced processing/accuracy, full recovery, team authorization/approved metadata sync, trust lifecycle and production distribution remain open. Seven core/interface emulator subsets do not pass the seven-full-workflow beta gate.

[Historical implementation log](https://github.com/TwoWetKnuckles/echoscript/blob/main/docs/qa/archive/IMPLEMENTATION-THROUGH-2026-11-13.md) preserves prior work and interrupted drafts. Historical statements do not override current status. Browser parity and packaged Termux remain deferred under [the owner decision](/docs/working-scope).
