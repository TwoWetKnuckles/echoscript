Development evaluation release for Android 10/API 29 or later. **BETA GATE: NOT PASSED.**

- ClearVoice FRCRN speech enhancement runs on the phone with a bundled, hash-verified model. Enable or disable it and choose before/after effects. Recipe replay retains the original base, placement and completed stages; disabling it does not compound an earlier enhanced result.
- Vosk remains the on-device default. Choose Whisper API before starting transcription to use the key already configured on your companion server. The phone prepares and hashes exact audio chunks, shows destination/model/payload details and requires approval before upload. Cancel sends nothing. Completed raw results can be reused on an approved retry.
- The workbench uses the documentation's graphite/cyan palette and bordered cards, with the existing compact effect groups, waveform/spectrum, examiner notes and non-destructive history.
- All implemented tools are available. Technical memory, storage, parser, codec and provider limits still apply.
- Inference telemetry is disabled before initialization. Originals, derivatives, raw provider responses, normalized transcripts and submission manifests retain encrypted storage and provenance.

## Installation

Install `EchoScript-Android10-Offline-Test-Candidate-0.6.apk` directly or extract the dedicated `EchoScript-Android` folder from `EchoScript-Android10-Offline-Test-Candidate-0.6.zip` and follow `INSTALL.txt`. The label is **EchoScript 0.6 Candidate**, application ID `org.echoscript.app.candidate06`, version `0.6.0-candidate.1` (code 9). Its separate vault starts empty and preserves earlier installed test apps. Retain and independently verify protected exports before any uninstall/reset.

Vosk and ClearVoice need no server or first-run model download. Whisper requires a configured companion address/session token; the OpenAI key stays server-side. Remote hosts require HTTPS; a loopback tunnel is supported. This remains a single-operator development companion. Project-specific OpenAI retention has not been qualified. API charges apply only when that route is explicitly approved.
