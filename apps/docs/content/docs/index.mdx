EchoScript is a local-first Android audio workbench under development. The latest **0.6 Test** preview includes local acquisition, waveform/spectral inspection, separate renders, on-device English transcription, examiner review and protected case transfer.

**Development preview for synthetic evaluation. BETA GATE: NOT PASSED.** The release record distinguishes executed emulator checks from outstanding physical-device and full-product acceptance.

## Start a workflow

1. [Download the APK or installation ZIP](/docs/downloads) and verify its SHA-256. Read the instructions before changing an installed preview.
2. In **Cases**, choose a recording, check its name under **Selected recording**, then tap **Import selected audio**.
3. In **Analyze**, listen, seek or drag a time selection. [Explore presets and effect controls](/docs/android/enhancement-workbench); render changes as a separate revision.
4. Review the transcript, uncertainty and speaker labels. Examiner notes are separate from spoken words; only an explicit examiner action verifies speech.
5. [Export a protected case](/docs/evidence/protected-transfer) and retain its passphrase, hash and any independently trusted signer reference separately.
